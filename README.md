# Менделеев БГ 🧪 / Mendeleev BG 🧪

Интерактивна периодична таблица на елементите на **български език** — проектирана за деца с ADHD, тъмна Tron естетика, оптимизирана за бързо изследване.

An interactive **Periodic Table of the Elements in Bulgarian** — designed for kids with ADHD, dark Tron aesthetic, optimized for fast exploration.

---

## ✨ Функции / Features

- 🇧🇬 Пълна периодична таблица на **български** / Full periodic table in **Bulgarian**
- 🎨 Тъмна Tron тема с цветно кодиране по групи / Dark Tron theme with group color-coding
- 🔍 Бързо търсене по символ, БГ/EN наименование, или атомен номер / Quick search by symbol, BG/EN name, or atomic number
- 📋 Подробна карта за всеки елемент: атомна маса, електронна конфигурация, точка на топене/кипене / Detailed card per element: atomic mass, electron config, melting/boiling points
- 🧒 Оптимизирано за 8-годишни деца / Optimized for 8-year-olds
- 📱 Работи в браузъра — без инсталация / Runs in the browser — no install needed
- 🌐 Самостоятелен HTML файл / Single self-contained HTML file

---

## 🚀 Как да използвате / How to Use

Отворете `periodic-table-bg.html` директно в браузъра. Не са нужни сървъри или зависимости.

Open `periodic-table-bg.html` directly in your browser. No server or dependencies needed.
